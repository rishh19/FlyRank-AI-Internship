Improving Content Prioritization Using Search Performance Signals

FlyRank ML Internship Capstone Research Paper

Abstract

This research investigates whether search performance metrics can help prioritize web content for optimization. A transparent rule-based baseline was first created and then compared with a Decision Tree classifier using the FlyRank ML Internship dataset. The analysis used search impressions, clicks, and average search position as input features together with an honest train/test validation design. The model demonstrated useful measured patterns relative to the baseline on the educational dataset. These findings are intended for decision-support and should not be interpreted as evidence of production performance.

Introduction / Problem Statement

Content teams often manage thousands of pages, making manual prioritization difficult. This project explores whether historical search-performance signals can help identify pages that deserve human review for content improvement. The objective is to support better decision making rather than automate publishing decisions.

Data

  • Dataset: FlyRank ML Internship Dataset (March 2026 release)
  • Main table: fact_content_daily_performance
  • Features: gsc_impressions, gsc_clicks, gsc_avg_position
  • Privacy: No client names, URLs, or private search queries were included.

Methodology

  • Built a rule-based baseline using search-performance thresholds.
  • Trained a Decision Tree classifier using the selected features.
  • Used an 80/20 train-test split for evaluation.
  • Performed a leakage review to avoid intentionally using future-window or target-derived information.
  • Compared the machine-learning model against the baseline using the same evaluation approach.

Results (Model vs Baseline)

The observed results suggest that the Decision Tree can support prioritization more effectively than the simple baseline within the educational dataset. Further validation would be required before production use.

Limitations

  • Educational target label rather than a production label.
  • Limited feature set.
  • Seasonality and external marketing factors were not modeled.
  • Results should be interpreted as directional and decision-support only.

Ranked Recommendations

  1. HIGH_IMPRESSIONS_LOW_CLICKS → Refresh content and improve titles or descriptions.
  2. LOW_VISIBILITY → Improve on-page SEO and keyword targeting.
  3. REVIEW_CONTENT → Perform manual editorial review before taking action.

Human review is required before implementing any recommendation.
